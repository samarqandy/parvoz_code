# Baza migratsiyalari

Supabase'ga MCP / CLI orqali qo'llanadi; bu yerdagi nusxa — tarix uchun.
Fayl nomidagi raqam Supabase'dagi migratsiya versiyasi bilan bir xil.

Bu papka 2026-09-27 dan boshlab yuritiladi. Undan oldingi migratsiyalar
(`attendance_system_init` … `attendance_absent_and_excused`) faqat
Supabase'dagi tarixda bor.

Supabase tarixidagi `lumora_init`, `lumora_enable_rls` va `drop_lumora_schema` bu
saytga tegishli emas (boshqa ilova shu bazada vaqtincha turgan, keyin Neon'ga
ko'chgan) — shuning uchun bu yerda nusxasi yo'q.
